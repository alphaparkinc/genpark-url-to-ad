# genpark-url-to-ad

Automated e-commerce short video factory.

Stop paying for closed SaaS apps. This is a terminal-native, open-source alternative to **Glato AI**.

Paste any product URL. The agent scrapes the copy, rewrites a viral short-form script, generates voiceover via local TTS, and stitches together an ad video using FFmpeg.

## Usage
```bash
openclaw use genpark-url-to-ad
```
